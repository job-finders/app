### Job Sidebar Enhancements

#### Dynamic Button States
The job sidebar now displays different states based on application progress:

##### 1. Application Submitted State (Existing)
- **Condition**: `user_has_applied` is true
- **Display**: Success alert with link to applications
- **Behavior**: No changes to existing functionality

##### 2. Application In Progress State (New)
- **Condition**: `application_in_progress` is true
- **Display**: Progress card with completion percentage and current step
- **Components**:
  - Progress bar showing completion percentage
  - Current step display with human-readable names
  - "Continue Application" button with workflow navigation
  - "View Details" button for progress modal

##### 3. No Application State (Enhanced)
- **Condition**: No existing application
- **Display**: Two primary action buttons
- **Components**:
  - "Start Application" button (enhanced with data attributes)
  - "Generate Cover Letter" button (new standalone option)

## Template Variables Required
The enhanced template expects these variables from the backend:
- `user_has_applied`: Boolean indicating if user already applied
- `application_in_progress`: Boolean indicating if application is in progress
- `application_progress`: Object with progress data if application exists
  - `completion_percentage`: Number (0-100)
  - `workflow_step_display`: String (human-readable step name)
  - `application_id`: String (application identifier)
  - `next_step`: String (next workflow step)
- `job.job_id`: String (job identifier for data attributes)
