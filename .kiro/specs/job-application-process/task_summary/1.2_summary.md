## Database Schema Overview

```
questionnaires
├── questionnaire_id (PK)
├── title, description, time_limit
├── is_active, timestamps
└── questions (1:N) → questionnaire_questions

questionnaire_questions
├── question_id (PK)
├── questionnaire_id (FK)
├── question_text, question_type
├── options (JSON), validation fields
└── answers (1:N) → questionnaire_answers

cover_letter_sessions
├── session_id (PK)
├── user_id, job_id, cv_id
├── draft_text, generated_letter
└── expiry management

questionnaire_submissions
├── submission_id (PK)
├── application_id, questionnaire_id, user_id
├── timing fields, completion status
└── answers (1:N) → questionnaire_answers

questionnaire_answers
├── answer_id (PK)
├── submission_id (FK), question_id (FK)
└── answer_data (JSON)
```
