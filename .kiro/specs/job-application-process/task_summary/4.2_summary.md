## Template Variables Required
The progress indicators expect these variables from the backend:
- `application_progress`: Object with detailed progress information
  - `completion_percentage`: Number (0-100)
  - `workflow_step`: String (current step identifier)
  - `workflow_step_display`: String (human-readable step name)
  - `application_id`: String (application identifier)
  - `next_step`: String (next workflow step)
  - `validation_score`: Number (0-100, optional)
  - `workflow_duration_minutes`: Number (optional)
- `job.required_questionnaire`: Array (for conditional questionnaire step display)
