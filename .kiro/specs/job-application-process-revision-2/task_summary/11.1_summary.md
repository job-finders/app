### Available Endpoints
With the blueprint registration, the following endpoints are now accessible:

- `POST /api/applications/workflow/cover-letter/sessions` - Create cover letter session
- `PATCH /api/applications/workflow/cover-letter/sessions/{id}` - Update cover letter session
- `POST /api/applications/workflow/applications/{id}/cover-letter` - Link cover letter to application

- `POST /api/applications/workflow/questionnaires/submit` - Submit questionnaire
