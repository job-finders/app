## API Integration

### New Endpoints
- `GET /api/applications/workflow/applications/{id}/questionnaires` - Display questionnaire page
- `POST /api/applications/workflow/questionnaires/save-progress` - Auto-save progress
- `POST /api/applications/workflow/questionnaires/submit` - Submit questionnaire

### Data Flow
1. **Page Load**: Fetch application, job, and questionnaire data
2. **Timer Start**: Initialize countdown and auto-save intervals
3. **Progress Save**: Periodic auto-save of answers and progress
4. **Validation**: Real-time validation of required questions
5. **Submission**: Final submission with workflow progression
