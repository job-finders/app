# AI Crawler Information

Welcome to the JobFinders.ai Crawlers Info page. Here you’ll find guidelines on how to access, crawl, and index our public data responsibly.

## 1. Data Usage Policy

- **Public Data Only**: You may crawl and index job listings, categories, and location summaries.  
- **No Personal Data**: User profiles, resumes, and applicant details are not exposed or crawlable.  
- **Respect Rate Limits**: Do not exceed 1,000 requests per day when using our API or crawling HTML endpoints.

## 2. Approved Crawlers

We explicitly allow the following agents, which respect our `robots.txt` directives and crawl responsibly:

| User-Agent             | Purpose                                  |
|------------------------|------------------------------------------|
| `Googlebot`            | Google Search indexing                   |
| `AdsBot-Google`        | Google Ads compatibility                 |
| `Bingbot`              | Microsoft Bing indexing                  |
| `GPTBot`               | OpenAI ChatGPT data ingestion            |
| `anthropic-ai`         | Anthropic Claude indexing                |
| `CCBot`                | Common Crawl dataset                     |
| `PerplexityBot`        | Perplexity AI search                     |
| `FacebookExternalHit`  | Meta link previews                       |
| `HuggingFaceBot`       | Hugging Face model demos                 |
| `archive.org_bot`      | Wayback Machine archives                 |
