# Application Workflow API Documentation\n\nThis document provides comprehensive documentation for the Job Application Workflow API endpoints.\n\n## Overview\n\nThe Application Workflow API manages the complete job application process from initial application creation through final submission. It includes cover letter generation, questionnaire completion, validation, and submission workflows.\n\n## Base URL\n\n```\n/api/applications/workflow\n```\n\n## Authentication\n\nAll endpoints require user authentication. Include the authentication token in the request headers:\n\n```http\nAuthorization: Bearer <your-jwt-token>\nContent-Type: application/json\n```\n\n## Endpoints\n\n### 1. Start Application Process\n\nInitiate the application workflow for a specific job.\n\n**Endpoint:** `POST /applications/start`\n\n**Request Body:**\n```json\n{\n  \"job_id\": \"string\",\n  \"user_id\": \"string\"\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"application_id\": \"app-12345\",\n  \"next_step\": \"cover_letter\",\n  \"cover_letter_exists\": false,\n  \"questionnaires_required\": true,\n  \"workflow_step\": \"draft\",\n  \"message\": \"Application process started successfully\"\n}\n```\n\n**Error Response:**\n```json\n{\n  \"success\": false,\n  \"message\": \"You have already applied for this job\",\n  \"application_id\": \"existing-app-id\",\n  \"workflow_step\": \"submitted\"\n}\n```\n\n### 2. Create Cover Letter Session\n\nCreate or update a cover letter generation session.\n\n**Endpoint:** `POST /applications/{application_id}/cover-letter/session`\n\n**Request Body:**\n```json\n{\n  \"cv_id\": \"cv-12345\",\n  \"draft_text\": \"Dear Hiring Manager...\",\n  \"selected_tone\": \"professional\"\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"session_id\": \"session-67890\",\n  \"message\": \"Cover letter session created successfully\"\n}\n```\n\n### 3. Update Cover Letter Session\n\nUpdate a cover letter session with generated content.\n\n**Endpoint:** `PUT /applications/{application_id}/cover-letter/session/{session_id}`\n\n**Request Body:**\n```json\n{\n  \"generated_letter\": \"Dear Hiring Manager,\\n\\nI am writing to express my strong interest...\"\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Cover letter session updated successfully\"\n}\n```\n\n### 4. Link Cover Letter to Application\n\nLink a completed cover letter session to the application.\n\n**Endpoint:** `POST /applications/{application_id}/cover-letter/link`\n\n**Request Body:**\n```json\n{\n  \"session_id\": \"session-67890\"\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Cover letter linked to application successfully\"\n}\n```\n\n### 5. Get Job Questionnaires\n\nRetrieve questionnaires required for a specific job.\n\n**Endpoint:** `GET /jobs/{job_id}/questionnaires`\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"questionnaires\": [\n    {\n      \"questionnaire_id\": \"tech-001\",\n      \"title\": \"Technical Assessment\",\n      \"description\": \"Evaluate technical skills and experience\",\n      \"time_limit\": 30,\n      \"questions\": [\n        {\n          \"question_id\": \"q1\",\n          \"question_text\": \"Describe your experience with Python\",\n          \"question_type\": \"text\",\n          \"required\": true,\n          \"max_length\": 500,\n          \"order_index\": 1\n        }\n      ]\n    }\n  ],\n  \"time_limit\": 30,\n  \"total_questions\": 5\n}\n```\n\n### 6. Start Questionnaire Timer\n\nStart the timer for questionnaire completion.\n\n**Endpoint:** `POST /applications/{application_id}/questionnaires/timer/start`\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Questionnaire timer started\",\n  \"started_at\": \"2024-01-15T10:30:00Z\",\n  \"time_limit_minutes\": 30,\n  \"total_questions\": 5\n}\n```\n\n### 7. Save Questionnaire Progress\n\nSave questionnaire progress for auto-save functionality.\n\n**Endpoint:** `POST /applications/{application_id}/questionnaires/progress`\n\n**Request Body:**\n```json\n{\n  \"questionnaire_id\": \"tech-001\",\n  \"answers\": {\n    \"q1\": [\"I have 5 years of Python experience...\"],\n    \"q2\": [\"Django\", \"Flask\"]\n  },\n  \"current_question\": 2,\n  \"time_spent\": 300\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Progress saved successfully\"\n}\n```\n\n### 8. Submit Questionnaire\n\nSubmit completed questionnaire answers.\n\n**Endpoint:** `POST /applications/{application_id}/questionnaires/submit`\n\n**Request Body:**\n```json\n{\n  \"questionnaire_id\": \"tech-001\",\n  \"answers\": {\n    \"q1\": [\"I have 5 years of Python experience in web development...\"],\n    \"q2\": [\"Django\", \"Flask\", \"FastAPI\"],\n    \"q3\": [\"4\"]\n  },\n  \"time_spent_seconds\": 1800,\n  \"is_auto_submit\": false\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Questionnaire submitted successfully\",\n  \"submission_id\": \"sub-12345\",\n  \"is_auto_submit\": false\n}\n```\n\n### 9. Validate Application\n\nValidate application completeness and requirements.\n\n**Endpoint:** `GET /applications/{application_id}/validate`\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"issues\": [\n    {\n      \"title\": \"Cover Letter Missing\",\n      \"description\": \"Adding a cover letter significantly improves your chances\",\n      \"action_url\": \"/jobs/job-123#cover-letter\",\n      \"action_text\": \"Add Cover Letter\"\n    }\n  ],\n  \"validation_score\": 75\n}\n```\n\n### 10. Submit Final Application\n\nSubmit the completed application.\n\n**Endpoint:** `POST /applications/{application_id}/submit`\n\n**Request Body:**\n```json\n{\n  \"confirmed\": true\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Application submitted successfully\",\n  \"application_id\": \"app-12345\",\n  \"reference_number\": \"APP12345\"\n}\n```\n\n### 11. Get Application Status\n\nRetrieve current application status and progress.\n\n**Endpoint:** `GET /applications/{application_id}/status`\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"application_id\": \"app-12345\",\n  \"workflow_step\": \"review\",\n  \"workflow_step_display\": \"Ready for Review\",\n  \"completion_percentage\": 90,\n  \"next_step\": \"submit\",\n  \"is_complete\": false,\n  \"application_stage\": \"DRAFT\",\n  \"validation_score\": 85,\n  \"has_cover_letter\": true,\n  \"has_ats_report\": true,\n  \"questionnaires_completed\": true,\n  \"applied_date\": null,\n  \"workflow_duration_minutes\": 45\n}\n```\n\n### 12. Save Application Draft\n\nSave application as draft.\n\n**Endpoint:** `POST /applications/{application_id}/draft`\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Draft saved successfully\"\n}\n```\n\n## Error Handling Endpoints\n\n### 13. Handle Workflow Error\n\nHandle and log workflow errors with recovery options.\n\n**Endpoint:** `POST /applications/{application_id}/error`\n\n**Request Body:**\n```json\n{\n  \"error_type\": \"validation\",\n  \"error_message\": \"Missing required field\",\n  \"recovery_options\": [\"fix_validation_errors\", \"save_draft\"]\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": false,\n  \"error_type\": \"validation\",\n  \"message\": \"Missing required field\",\n  \"recovery_options\": [\"fix_validation_errors\", \"save_draft\"],\n  \"error_id\": \"app-12345_1642248600\",\n  \"support_contact\": \"support@jobfinders.site\"\n}\n```\n\n### 14. Preserve Session Progress\n\nPreserve session progress to prevent data loss.\n\n**Endpoint:** `POST /applications/{application_id}/session/preserve`\n\n**Request Body:**\n```json\n{\n  \"progress_data\": {\n    \"current_step\": \"questionnaires\",\n    \"answers\": {\"q1\": [\"answer1\"]},\n    \"time_spent\": 300\n  }\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Progress saved successfully\",\n  \"expires_at\": \"2024-01-16T10:30:00Z\"\n}\n```\n\n### 15. Restore Session Progress\n\nRestore previously saved session progress.\n\n**Endpoint:** `GET /applications/{application_id}/session/restore`\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"progress_data\": {\n    \"current_step\": \"questionnaires\",\n    \"answers\": {\"q1\": [\"answer1\"]},\n    \"time_spent\": 300\n  },\n  \"restored_from\": \"session\",\n  \"saved_at\": \"2024-01-15T10:30:00Z\"\n}\n```\n\n### 16. Extend Session Timeout\n\nExtend session timeout for active applications.\n\n**Endpoint:** `POST /applications/{application_id}/session/extend`\n\n**Request Body:**\n```json\n{\n  \"extension_minutes\": 30\n}\n```\n\n**Response:**\n```json\n{\n  \"success\": true,\n  \"message\": \"Session extended by 30 minutes\",\n  \"new_expiry\": \"2024-01-15T11:30:00Z\"\n}\n```\n\n## Data Models\n\n### ApplicationWorkflowResult\n\n```json\n{\n  \"success\": \"boolean\",\n  \"message\": \"string\",\n  \"application_id\": \"string\",\n  \"next_step\": \"string\",\n  \"cover_letter_exists\": \"boolean\",\n  \"questionnaires_required\": \"boolean\",\n  \"workflow_step\": \"string\"\n}\n```\n\n### QuestionnaireResult\n\n```json\n{\n  \"success\": \"boolean\",\n  \"questionnaires\": \"array\",\n  \"time_limit\": \"integer\",\n  \"total_questions\": \"integer\",\n  \"message\": \"string\"\n}\n```\n\n### ValidationResult\n\n```json\n{\n  \"is_valid\": \"boolean\",\n  \"is_complete\": \"boolean\",\n  \"score\": \"integer\",\n  \"missing_fields\": \"array\",\n  \"validation_errors\": \"array\"\n}\n```\n\n## Error Codes\n\n| Code | Description |\n|------|-------------|\n| 400 | Bad Request - Invalid input data |\n| 401 | Unauthorized - Authentication required |\n| 403 | Forbidden - Insufficient permissions |\n| 404 | Not Found - Resource not found |\n| 409 | Conflict - Resource already exists |\n| 422 | Unprocessable Entity - Validation failed |\n| 500 | Internal Server Error - System error |\n\n## Rate Limiting\n\nAPI endpoints are rate limited to prevent abuse:\n\n- **General endpoints**: 100 requests per minute per user\n- **Progress saving**: 10 requests per minute per application\n- **Session management**: 20 requests per minute per user\n\n## Webhooks\n\nThe system supports webhooks for real-time notifications:\n\n### Application Submitted\n\n```json\n{\n  \"event\": \"application.submitted\",\n  \"timestamp\":
